## 🎮 Como jogar
- Clique nas cartas para revelar os símbolos
- Encontre os pares iguais
- Se errar, as cartas viram novamente

## 🚀 Como executar
1. Baixe o projeto
2. Abra o arquivo `index.html` no navegador

## 📌 Funcionalidades
- Cartas embaralhadas automaticamente
- Sistema de acerto e erro
- Interface simples e intuitiva
